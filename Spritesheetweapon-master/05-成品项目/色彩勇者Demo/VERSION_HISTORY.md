# 版本迭代记录

## 2.4.1 战斗可读性与奖励协同

- 合法交换支持选中后悬停预览，展示首轮消除、色素、可触发色谱、谱序共鸣和敌人风险。
- 预览通过快照进行纯读取演算，不修改棋盘、色谱进度、随机状态、统计或存档。
- 修复色谱触发器在没有新触发时的循环条件错误，避免战斗预览和无效条件造成卡死。
- 识别三连、四连、五连、L/T 形和十字形消除，并在预览与战斗反馈中明确标注。
- 四连、五连、L/T 与十字消除增加局部放大后消散的短动画，普通三连保持原有节奏。
- 战后色谱奖励卡增加证据型推荐：当前角色契合、已完成流派延续或现有牌组联动；无依据时不显示推荐。
- 奖励卡提高固定高度，确保推荐文案在 1280×720 和 1600×900 下不会挤压操作按钮。

## 2.4.0 色谱构筑与战术验证

- 保留 6×6 四色三消、三步回合、色谱即时结算、谱序共鸣和 Save v4/Profile v1。
- 新增色谱构筑标签查询、战斗中的目标色谱标记与存档恢复。
- 新增首轮合法交换只读预览接口，明确不预测随机补块造成的完整级联。
- 色谱卡牌和战后奖励展示构筑标签，流派统计记录色谱完成与奖励选择。
- 暂不包含八色棋盘、完整特殊棋子、角色双分支、城市科技树和大规模新卡扩容。

## 2.3.0 复兴议会

- 新增每章政策、路线建设项目、复兴议会入口与建设进度。
- 修复节点重复结算与负数资源支付边界。
- 2.2 的棋盘安全、战斗反馈和 UI 生命周期修复继续保留。

## 2.2.0 Remaster（已验证）

- 当前实际色谱目录统一为 119 张：116 张可收集色谱与 3 张事件诅咒；117 仅是旧 2.0 文档基线。
- 延续 2.1 的战斗稳定检查点恢复，并强化 Board 快照的原子拒绝、棋盘可玩性校验、权重清洗和极端有限权重归一化。
- Tile 复用现有宝石 PNG，Tooltip 改为描述真实的色素、技能充能、燃烧、冻结概率、金币上限和灰蚀转化；减少动态/快速结算会取消旧 Tween。
- BattleManager 使用类型化战斗反馈合同；普通消除、色谱结算、谱序、敌人行动和终局反馈按因果顺序进入 Main 的非阻塞反馈条。
- Main 调整为更宽的棋盘/色谱舞台；重复卡刷新同步清理旧节点，旧场景先隐藏并禁用，避免延迟回调继续绘制。
- SettingsManager 对首次事件使用持久化白名单；首次提示写入既有日志，不增加阻塞教程或经济变化。
- Infinite Canvas 已重新连接本地 agent；3 次图像请求因 `No available compatible accounts` 失败，2.2 没有新的 AI 位图交付。
- 本版本不包含完整 Meta Progression、商店/遗物重做、全量数值平衡重做或新存档协议。
- 2.2 新套件、全量回归、视觉检查和导出结果：待本轮验证结果补录。

## 2.1.0 断点续行与地图记忆

- 新增战斗中断恢复：Run Save v4 在稳定检查点记录棋盘、敌人状态、护甲、持续效果、回合、剩余步数、色谱手牌、触发历史和战斗上下文；恢复时不会重复执行开场效果。
- 新增稳定检查点边界：结算中、胜负已确定或节点不匹配时不写入战斗快照；非法棋盘快照必须被拒绝，且恢复棋盘必须保持可交换、无预成消除。
- 存档改为临时文件校验后原子替换，并保留 `.bak` 轮换；主档损坏或缺失时可回退到备份，避免一次写入故障覆盖有效进度。
- 地图视图记忆持久化当前章节的缩放、平移和聚焦节点；进度变化后自动聚焦最新可达节点，窗口失焦、隐藏或退出树时清理拖拽状态。
- 修复扩展色谱学派完成计数恢复：紫、绿、白、混色、黑等合法字符串键不再被四色基础统计白名单截断；负数值统一钳制为 0。
- 胜利奖励事务提前于胜利演出落盘，缩短关闭窗口或进程中断造成奖励丢失的时间窗；新增 2.1.0 存档、地图、战斗恢复与发布边界测试。
- 2.1.0 发布验收：Godot 4.6.3 冷解析通过；专项回归包含恢复 8/8、存档 14/14、地图 7/7、2.x 套件 12/12，通过后再执行全量 36 脚本回归与 Windows 发布包验收。

## 2.0.0 断色回廊

- 战斗架构重写为“纯三消 + 色谱卡牌”：普通消除不直接扣除敌人 HP；消除产生色素并推进三张色谱，色谱达成后在当前操作链内立即结算伤害、护盾、控制、回复、经济或棋盘改造。
- 固定 6×6 四色棋盘、每回合 3 次有效交换、3 张手牌与最多保留 1 张未达成色谱；无合法交换自动重排，高灰蚀棋盘提供净化保护。
- 色谱成为战斗输出与构筑的唯一卡牌载体。正式目录为 117 张：114 张可收集色谱与 3 张事件诅咒；遗物维持 72 件，事件扩充至 54 个。
- 新增跨回合谱序共鸣：上一回合最后达成的有效色谱为引音，下一回合第一张有效色谱为应音；每回合最多触发一次，共鸣只修正应音色谱的当次结算。
- 九学派统一映射为同频和声、紫弦折射、翠生回路、熔金脉冲、白昼三和与消色回声六类共鸣，所有收益受单卡与单回合预算上限约束。
- 五名角色在最大 HP、起始牌组、被动、主动技、专属池和角色挑战上形成独立身份：烬歌偏爆发，凛镜偏防御反制，洛恩偏经济，弥砂偏灰蚀净化，伊澜偏多色谱序。
- 守序、破谱、见证三项誓约分别固定 `standard`、`risk`、`economy` 地图池；每章同步 `archive` 档案池作为完成记忆组后的第四类轮换模板。
- 断色回廊扩充为 M01-M30 共 30 枚记忆、10 组完整记忆与 3 个回想槽；默认发现 M01-M03，重复发现转化为记忆墨。
- 54 个事件中包含 18 个 2.0 碎片叙事事件。记忆与事件证词可提供地图情报、角色选项、棋盘或色谱修正、Boss 干预和复调终局证据。
- 敌人压力统一为公开意图，包括攻击、重击、防御、污染、锁格、改色、封谱、抗性、偷取与回复；三名 Boss 在 65% 与 30% HP 阈值切换规则。
- A0-A10 重新以敌人、经济、灰蚀、锁格、封谱和抗性压力递进，并为 HP、伤害、抗性、灰色权重与锁格数量设置硬上限。
- 结算统计改为有效交换率、平均每回合色谱达成、最高级联、共鸣率与最高单卡伤害，并保留学派、承伤、护盾、经济、记忆和结局证据明细。
- 局内存档维持 Run Save v4，跨局档案使用 Profile v1；保存誓约、地图模板、牌组、遗物、回想、奖励领取与统计，并保留 v1-v3 迁移链。
- 当前发布验收以纯三消专项测试为准：必须验证普通消除伤害为 0、色谱即时结算、谱序生命周期、30/10/3 记忆边界、四类地图可达、Run Save v4/Profile v1 往返与当前 UI 无第二操作层。
- 旧版本兼容测试只用于证明迁移和历史行为可追溯，不计作 2.0 当前战斗架构的验收结果。

## 1.4.0 三章钉盘生态

- 内容扩展到 84 张可收集棋谱、72 件遗物与 36 个事件；新增内容均围绕射击、钉点与章节机制。
- 新增三章 12 套 9x8 确定性钉盘：火焰/雾、镜面/弹簧/抗性、王锁/虚无/危险钉。
- 敌人新增偏折、临界压制、布雷和封钉四类下一发干扰，具备预告、单发持续与清除边界。

## 1.3.0 钉点构筑

- 遗物从 48 件扩展到 60 件，事件从 24 个扩展到 30 个。
- 新增暴击、回声、悬赏、穿透四条钉板强化线，商店和事件均可获得，最高 3 级。
- 钉板强化完整接入伤害、暴击率、金币收益、穿透与存档恢复。
- 12 件新遗物改变红/蓝/金/灰/混色弹型、回声钉、危险钉、首发弹与队列齐射。
- 六个钉板事件加入三章事件池，并覆盖资源不足、满级拒绝和节点事务。

## 1.2.0 谱弹重构

- 棋盘从 7x7 调整为 6x6，基础灰色权重从 66% 降至 43%。
- 战斗因果链改为“消除产色素并触发颜色基础效果 -> 推进棋谱 -> 生成谱弹 -> 瞄准命中 -> 伤害结算”。
- 普通消除不立即造成 HP 伤害；燃烧等持续状态会在其结算时点生效，红釉剑柄等明确例外可生成低伤碎弹。
- 新增确定性弹珠解析、暴击钉、金币钉、穿透、多球和轨迹回放。
- 五名角色新增不同主动技与弹型：高速弹、折射弹、套利弹、净雾重弹、棱镜多球。
- 三章各新增标准、高危、经营 3 张地图模板，选择由运行 Seed 决定并写入存档。
- 地图继续支持滚轮缩放、鼠标拖拽、按钮缩放与复位。
