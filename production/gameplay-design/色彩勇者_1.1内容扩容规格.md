# 《色彩勇者：三消镇魂曲》1.1 内容扩容规格

> 文档状态：可直接落地的数据规格草案
>
> 版本目标：1.1「五声回响」
>
> 基线：Godot 4.6，1.0 运行时规则与 `GameData.gd` / `GameManager.gd` 当前字段
>
> 本文只定义内容、数据和验收口径，不修改运行时代码。

## 1. 版本目标与范围

### 1.1 版本目标

1. 让每一局的核心决策从“选择三张色谱”扩展为“角色被动 + 学派色谱 + 遗物 + 路线事件”的四层构筑。
2. 保持棋盘易读和 1.0 的操作节奏：棋盘仍为 7x7，每回合 3 步，基础块只允许红、蓝、金、灰。
3. 在不强制拉长基础流程的前提下，让玩家在第 2 章开始看到明显的路线分化，在第 3 章形成角色专属终局构筑。
4. 提供正式角色选择界面所需的完整数据：5 名角色、5 个被动、5 套起始牌组原则和 5 个专属池。
5. 将内容规模扩展为：72 张可收集非诅咒色谱、48 件遗物、24 个事件、6 个挑战节点；现有 1.0 内容全部保留。

### 1.2 数量口径

| 内容 | 1.0 现状 | 1.1 目标 | 本文新增 |
|---|---:|---:|---:|
| 可收集非诅咒色谱 | 36 | 72 | 36 |
| 诅咒色谱 | 1（《黑曜契约》） | 1+ | 0，继续独立计算 |
| 遗物 | 24 | 48 | 24 |
| 事件 | 12 | 24 | 12 |
| 正式角色 | 3 个起始流派 | 5 名角色 | 2 名全新角色，3 个旧流派角色正式化 |
| 挑战节点 | 0 | 6 个节点模板 | 6 |
| 基础棋盘颜色 | 红、蓝、金、灰 | 不变 | 0 |

“72 色谱”指可进入普通奖励池、商店或专属池的非诅咒色谱总数；诅咒色谱只由事件、遗物或特殊节点加入，永远不占普通 72 张配额。

### 1.3 不变规则

- 棋盘固定为 7x7；单回合基础移动数为 3。
- 棋盘基础块只使用 `red`、`blue`、`gold`、`gray`。`green`、`purple`、`white`、`black` 只能出现在色谱学派、角色池、遗物、事件和状态标签中，不得进入 `COLOR_ORDER` 或掉落权重。
- 色谱仍是自动触发的三消目标契约，不是玩家点击后释放的技能。
- 伤害倍率保持 1.0：3 连 1.0，4 连 1.5，5 连 2.5，6+ 连 4.0；级联倍率为 `1 + (cascade - 1) * 0.35`；红色基础伤害乘 1.5。
- 手牌上限仍为 3；基础保留位为 1；《无色冠冕》仍只额外提供 1 个保留位。
- 普通路线仍为三章，每章 8 层；挑战节点替换同层的一个普通/事件候选，不额外增加必经层数。

## 2. 1.1 数据契约

### 2.1 色谱对象

新色谱沿用 `GameData.SPECTRA` 的兼容字段，并追加 1.1 字段。现有卡不用立即重写，但加载器应为旧卡补齐默认值。

```text
{
  "id": "verdant_recovery",
  "name": "青芽回生",
  "color": "gray",
  "school": "green",
  "rarity": "common",
  "condition": "本回合累计灰色 >=5 且 HP <=70%",
  "condition_type": "turn_color_total_and_hp_ratio",
  "threshold": 5,
  "hp_ratio_at_most": 0.70,
  "effect": "回复 6 HP，净化 1 个灰块。",
  "effect_type": "heal_and_cleanse",
  "heal": 6,
  "cleanse_count": 1,
  "pools": ["common", "green", "character_greengrove"],
  "route_tags": ["recovery", "gray_control"],
  "once_per_turn": true,
  "upgrade": {
    "condition": "本回合累计灰色 >=4 且 HP <=70%",
    "threshold": 4,
    "heal": 8,
    "cleanse_count": 1
  }
}
```

字段约束：

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | string | 全局唯一，snake_case；1.1 新卡统一使用 `v11_` 前缀。 |
| `color` | string | 触发来源色，必须是现有红、蓝、金、灰，或兼容旧卡的 `neutral` / `mixed`；不填绿紫白黑。 |
| `school` | string | 主题学派，可为 `red`、`blue`、`gold`、`gray`、`green`、`purple`、`white`、`black`。 |
| `rarity` | string | 只允许 `common`、`rare`、`epic`；诅咒仍使用 `curse`。 |
| `condition_type` | string | 必须落在本文 2.2 的白名单中；禁止只写自然语言而没有可解析类型。 |
| `effect_type` | string | 必须落在本文 2.3 的白名单中；复合效果按固定顺序结算。 |
| `pools` | Array | 至少含稀有度池和学派池；角色专属卡还要含 `character_xxx`。 |
| `once_per_turn` / `once_per_battle` | bool | 所有资源生成、额外移动和抽牌效果至少有一个触发上限。 |
| `upgrade` | Dictionary | 只改阈值或数值，不改变卡的核心学派和触发语义。 |

### 2.2 条件类型白名单

`turn_color_total`、`match_size`、`event_count`、`sequence`、`cascade`、`completed_count`、`completed_color_set`、`remaining_moves`、`enemy_intent`、`enemy_status`、`player_hp_ratio`、`shield_at_least`、`coins_at_most`、`gray_pressure_at_least`、`no_damage_taken`、`all_player_colors`、`same_color_limit`、`draw_or_retain`、`challenge_flag`。

组合条件最多 3 个原子条件，统一使用 AND；除专门标注外不允许 OR，避免玩家无法预测。

### 2.3 效果类型白名单

`damage`、`damage_and_burn`、`damage_and_resistance`、`shield`、`shield_and_damage_reduction`、`freeze_or_interrupt`、`draw`、`retain_bonus`、`coins`、`pigment`、`heal`、`cleanse`、`heal_and_cleanse`、`cleanse_and_pressure_reduce`、`dye_gray`、`extra_move`、`enemy_debuff`、`conditional_copy`。

效果结算顺序固定为：伤害/状态 -> 防御/回复 -> 资源 -> 抽牌/保留 -> 棋盘净化或染色。新效果不得递归触发自身，也不得通过抽牌再次完成同一实例。

每名角色初始牌组固定 8 张，遵守“4 张角色核心 + 2 张跨色支撑 + 2 张通用基础”原则。实际 ID 可由实现阶段从 1.0 与 1.1 牌表抽取，但不得改变以下结构：

|---|---|---|---|---|
| 炎律骑士 | 2 红色普通、1 红色稀有、1 红色角色专属 | 1 蓝防御、1 金经济 | 1 中立级联、1 灰净化 | `warm_charm` |
| 镜湖守卫 | 2 蓝色普通、1 蓝色稀有、1 蓝色角色专属 | 1 红伤害、1 白昼恢复 | 1 中立级联、1 灰净化 | `frozen_watch` |
| 金辉旅商 | 2 金色普通、1 金色稀有、1 金色角色专属 | 1 红伤害、1 灰烬转化 | 1 蓝防御、1 中立级联 | `merchant_seal` |

## 4. 72 色谱的学派与配额

### 4.1 学派定义

学派是色谱的构筑标签，不是棋盘颜色。每张色谱同时拥有一个触发来源 `color` 和一个主题 `school`。1.0 的 `neutral` / `mixed` 卡保留原字段，并在迁移表中补充学派标签。

| 学派 | ID | 总配额 | 1.0 归档 | 1.1 新增 | 核心玩法 |
|---|---|---:|---:|---:|---|
| 红焰 | `red` | 12 | 8 | 4 | 伤害、燃烧、生命换爆发 |
| 蓝霜 | `blue` | 12 | 8 | 4 | 护盾、冻结、意图打断 |
| 金辉 | `gold` | 12 | 8 | 4 | 金币、商店、收益转化 |
| 灰蚀 | `gray` | 10 | 5 | 5 | 净化、压力、灰块转化 |
| 绿生 | `green` | 8 | 0 | 8 | 回复、净化、低 HP 复原 |
| 紫冥 | `purple` | 8 | 3* | 5 | 级联、阈值、延迟风险 |
| 白昼 | `white` | 5 | 2* | 3 | 跨色校准、解除负面、稳定收益 |
| 黑曜 | `black` | 5 | 2* | 3 | 自伤、诅咒、极限步数 |
| **合计** |  | **72** | **36** | **36** |  |

`*` 迁移标签：`palette_drill`、`tone_phrase` 归入白昼；`ash_alchemy`、`prism_concerto`、`colorless_pause` 归入紫冥；`daylight_calibration`、`finale_variation` 归入黑曜。学派标签不改变这些旧卡的触发色或效果。`obsidian_contract` 为诅咒，不计入 72 张。

新增 36 张的稀有度配额：普通 18、稀有 12、史诗 6。新增学派配额为：红焰 4、蓝霜 4、金辉 4、灰蚀 5、绿生 8、紫冥 5、白昼 3、黑曜 3，共 36 张。

### 7.2 挑战节点生成

- 每章第 2、4、6 层各抽取 1 个挑战候选，最终只展示 2 个，避免路线图过载。
- 每局至少出现 2 个挑战节点候选，最多被玩家选择 3 次。
- 角色专属挑战权重：当前角色所属学派的挑战权重 +30%；已经完成对应事件链时再 +20%。
- 挑战节点不与 Boss 前营火重叠；若同层没有安全替代节点，生成器必须回退为普通节点。
- 选择挑战后地图节点显示规则、预期风险、奖励稀有度；不得用隐藏词条制造不可预测伤害。

### 7.3 角色专属路线规则

1. 角色卡进入路线图前锁定，单局不可中途切换角色；角色选择界面必须显示基础 HP、被动、初始遗物、专属池预览。
2. 当前角色专属学派挑战和事件链节点权重 +30%，但不会保证出现；每章至少保留一个非专属安全路线。
3. 角色专属卡进入普通奖励的条件为：角色已解锁且本局角色匹配；其他角色只能通过特殊事件的“跨色”选项获得最多 1 张。
4. 角色专属路线不提供额外基础攻击力；所有优势必须通过触发条件、路线风险或资源机会成本体现。
5. 角色专属结局判定使用“本场完成专属学派色谱 >=4”或“完成对应事件链”，不使用永久数值。

| 单回合抽牌 | 色谱、遗物和被动合计最多额外抽 2 张。 |
| 单回合净化 | 最多 4 格；单次效果最多 3 格。 |
| 色谱触发 | 单个实例每回合最多触发 1 次；资源型史诗每战最多 1 次。 |
| 色谱伤害 | 普通额外伤害 8-24；稀有 18-48；史诗 40-70。 |
| 色谱护盾 | 普通 5-22；稀有 8-35；史诗 18-45。 |
| 金币 | 单战新增金币建议 12-36，绝对上限 60；全局额外金币来自事件/遗物时单局不超过 120。 |
| 颜料 | 单战新增不超过 2；单局建议 4-12，绝对上限 20。 |
| 灰蚀压力 | 建议上限 12；达到 10 后只允许通过色谱、营火或事件降低；不得出现负数。 |
| 自伤 | 单个效果 1-4 HP；单战新内容自伤总量不超过 10 HP。 |

### 9.2 路线与节奏边界

- 基础通关时长保持 60-90 分钟；挑战节点和事件链通过替换同层节点实现，不额外增加必经战斗。
- 普通战目标 TTK：第一章 3-6 回合，第二章 4-7 回合，第三章 5-8 回合。
- 精英战目标 TTK：第一章 5-8 回合，第二章 6-10 回合，第三章 8-12 回合。
- Boss 战目标 TTK：第一章 7-11 回合，第二章 9-13 回合，第三章 10-15 回合。
- 单局玩家应至少看到 2 个挑战节点候选、3 个新事件中的至少 1 个、1 件新增遗物候选和 2 张新增色谱候选。
- 新增内容在第一章只开放普通新增卡和 1 条事件链；第二章开放稀有、挑战节点和第二条事件链；第三章开放史诗、黑曜风险和最终链奖励。

## 10. 角色选择界面验收口径

1. 首屏同时展示 5 名角色，卡面固定显示：角色名、定位、基础 HP、被动短句、起始遗物、专属学派图标。
2. 悬停或点击详情显示 8 张初始牌组的学派分布和前 3 张专属池预览，不直接展示所有未解锁内容。
3. 选中角色后必须有明确的确认态；返回不会重置进阶难度或存档设置。
4. 旧存档若 `starting_archetype_id` 为 `red`、`blue`、`gold`，迁移到 `ember_knight`、`mirror_guard`、`gilded_merchant`，旧角色的牌组和遗物保持不变。
5. 新角色首次使用不会获得永久数值加成；解锁只开放角色、专属池和图鉴记录。

## 11. 验收指标

### 11.1 数据完整性

- 非诅咒色谱总数严格为 72；新增 `v11_` 色谱严格为 36，ID 无重复。
- 新增色谱稀有度严格为普通 18、稀有 12、史诗 6；学派新增配额严格为 4/4/4/5/8/5/3/3。
- 新增遗物严格为 24，ID 无重复，普通 12、稀有 10、Boss 2；所有遗物都存在触发范围和上限。
- 新增事件严格为 12；每个事件至少 2 个选项；4 条事件链均能从第一章进入并在后续章节闭环或明确中断。
- 角色严格为 5；每名角色有基础 HP、被动、8 张初始牌组原则、起始遗物、专属池。
- 棋盘颜色枚举和基础权重测试必须仍只命中红、蓝、金、灰。

### 11.2 玩法质量

- 5 名角色在 A0 的完整通关率目标为 35%-65%；任一角色低于 25% 或高于 75% 需先调起始牌组/路线权重。
- 五角色在 A0 的平均通关时长均落在 60-90 分钟；中位数差异不超过 12 分钟。
- 新增色谱在玩家实际牌组中的选择率目标为：普通 8%-25%，稀有 10%-35%，史诗 15%-45%；低于 5% 的卡必须复核触发可见性。
- 事件选项分布不得出现单一选项选择率超过 85%；超过时优先提高另一选项信息量或调整代价，不直接加奖励。
- 挑战节点选择率目标 20%-45%；选择挑战后的死亡率不高于同章精英路线的 1.4 倍。
- 角色专属事件链完成率目标 20%-50%；链奖励领取率不低于触发率的 60%。
- 由于新学派不进入棋盘，任何“绿/紫/白/黑块生成、掉落、匹配”断言都必须为 0。
