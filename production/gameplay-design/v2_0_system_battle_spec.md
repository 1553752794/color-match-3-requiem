# 《色彩勇者》2.0 系统与战斗规格

> 规格版本：2.0-pure-match-1  
> 当前架构：纯三消 + 色谱卡牌  
> 基准分辨率：1280×720  
> 存档：Run Save v4 / Profile v1

## 1. 版本决策

2.0 的唯一战斗主循环为：

`观察敌人意图 -> 选择色谱目标 -> 进行有效交换 -> 消除产色素并推进色谱 -> 色谱达成立即结算 -> 敌人行动`

冻结规则：

1. 普通消除不直接扣除敌人 HP。
2. 色谱卡牌是主要伤害、护盾、控制、回复、经济和棋盘改造来源。
3. 色谱达成后立即结算，不进入第二操作阶段。
4. 每回合的策略输入只有棋盘交换、主动技、保留选择和结束回合确认。
5. 谱序共鸣只修正当前达成色谱的结算，不创建独立攻击对象。
6. 同一输入、Seed、手牌顺序与棋盘状态必须得到相同结果。

1.2-1.5 使用的旧输出子系统已退役。旧版本的实现与测试只作为迁移和历史回归资料，不再定义 2.0 当前玩法。

## 2. 产品目标

### 2.1 核心体验

- 三消负责空间规划：交换哪里、制造多大连线、是否追求级联。
- 色谱负责构筑规划：本回合完成哪张、先完成哪张、保留哪张。
- 敌人意图负责风险规划：防守、打断、净化或抢先输出。
- 谱序负责跨回合规划：上一回合留下什么引音，下一回合用什么应音。
- 路线、角色、遗物、誓约与记忆负责单局构筑和多局变化。

### 2.2 非目标

- 不加入与三消无关的额外攻击小游戏。
- 不让普通消除按格数直接换算敌人 HP。
- 不使用无法预览的物理随机作为主要输出来源。
- 不增加第五种基础棋子。
- 不加入战斗中途保存；续局仍从节点外状态恢复。

## 3. 战斗状态

### 3.1 固定边界

| 项目 | 2.0 规则 |
|---|---|
| 棋盘 | 6×6 |
| 基础棋子 | 红、蓝、金、灰 |
| 基础手牌 | 3 张色谱 |
| 每回合步数 | 3 次有效交换 |
| 基础保留 | 回合结束最多保留 1 张未达成色谱 |
| 初始牌组 | 8 张 |
| 主动技充能 | 0-20 |
| 灰蚀压力 | 0-20 |
| 级联记录 | 1-12，超过按 12 统计 |
| 单次效果重复 | 1-4 |

### 3.2 战斗开始

结算顺序：

1. 读取角色、A0-A10、遗物、誓约和回想槽。
2. 创建敌人并公开第一个意图。
3. 生成 6×6 棋盘并校验至少存在一个合法交换。
4. 洗牌后抽取 3 张色谱。
5. 应用开局护盾、技能充能、棋盘改色和记忆效果。
6. 清空谱序引音、尾音和本战临时计数。
7. 进入玩家第 1 回合。

### 3.3 玩家回合

1. 补牌至 3 张。
2. 将上回合尾音复制为本回合引音。
3. 清空本回合尾音、颜色事件和共鸣消费标记。
4. 玩家可以发动满足条件的主动技。
5. 玩家交换相邻棋子。
6. 只有形成横向或纵向 3 个及以上同色连线的交换才消耗 1 步。
7. 解析当前消除、下落补充和全部级联。
8. 每个消除事件依次产色素、执行颜色基础效果并推进三张色谱。
9. 任一色谱首次达成时立即创建只读结算快照并执行效果。
10. 当前交换的所有级联和色谱效果全部完成后扣除 1 步。
11. 步数为 0 且没有待处理效果时，敌人执行公开意图。

## 4. 棋盘规则

### 4.1 生成权重

基础权重：

| 颜色 | 基础权重 | 主要用途 |
|---|---:|---|
| 灰 | 43% | 压力、净化、跨色条件 |
| 红 | 19% | 伤害、燃烧、生命代价 |
| 蓝 | 19% | 护盾、冻结、打断 |
| 金 | 19% | 金币、颜料、资源转换 |

灰蚀压力可以提高灰色权重，但最终灰色生成权重不得超过 64%。白、黑、紫、绿和混色只属于色谱学派，不加入基础棋子池。

### 4.2 消除价值

| 连线规模 | 基础色素 | 强拍值 |
|---:|---:|---:|
| 3 | 3 | 0 |
| 4 | 5 | 1 |
| 5 | 8 | 2 |
| 6+ | 11 + 超出格数 | 3 |

- 第 2 层级联起，每层额外提供 1 点对应色素，上限 5。
- 强拍值只供色谱条件、角色被动和结算增幅读取，不直接造成伤害。
- 同一棋子不得在同一消除事件中重复计数。
- 横纵交叉按一次消除事件记录，但格数取去重后的合集。

### 4.3 死局与高污染保护

- 棋盘没有合法交换时立即重排，重排不消耗步数。
- 重排必须保持棋子总数，不触发色谱进度。
- 灰格占比超过 72% 时自动净化 2 格；同一次下落链只执行一次。
- 自动净化优先选择不会立即形成免费连线的位置。
- 棋盘生成、重排和净化均使用战斗 Seed 派生随机源。

## 5. 色谱卡牌

### 5.1 卡牌合同

每个牌组实例至少包含：

```text
instance_id
card_id
level
color_school
condition_type
condition_value
effects[]
upgrade
rarity
pools[]
```

同名色谱拥有独立 `instance_id` 和进度。精研只强化选中的实例，不同步修改同名副本。

### 5.2 条件类型

正式白名单：

- 单色累计、四色累计、颜色种类数。
- 最大连线、级联深度、主动交换颜色。
- 颜色先后序列、已达成色谱数量、已达成学派数量。
- 剩余步数、HP 区间、护盾、金币、灰蚀压力。
- 敌人燃烧、敌人意图、是否受到污染、是否本回合受伤。
- 同回合颜色事件数与指定色未受伤条件。

未知条件必须显示为不可达成并写入数据校验错误，禁止静默视为完成。

### 5.3 结算原则

- 达成发生在消除事件提交后。
- 普通消除造成的敌人直接伤害恒为 0。
- 色谱结算快照固定卡牌等级、角色、遗物、誓约、回想、引音、应音和当前战斗状态。
- 结算开始后不再读取后续手牌变化。
- 诅咒色谱可以产生自伤、灰蚀或资源代价，但不能拥有正基础伤害。
- 达成后的卡牌进入弃牌堆；未达成卡牌按保留规则处理。

### 5.4 同事件多卡顺序

1. 先按首次满足条件的消除事件序号排序。
2. 同一事件中并列达成时按手牌槽从左到右。
3. 每张色谱完整结算后再处理下一张。
4. 抽牌效果只补到空槽，不改变已经建立的结算队列。
5. 新抽到的色谱不能追溯读取本回合早先事件。
6. 结算过程中敌人 HP 降至 0，仍完成当前色谱的资源与档案收益，然后结束战斗；后续卡牌不再结算。

### 5.5 效果顺序

单张色谱按以下顺序执行：

1. 支付自伤、金币、颜料等代价。
2. 计算角色与精研修正。
3. 计算谱序共鸣。
4. 造成伤害并处理护甲、抗性与阶段阈值。
5. 施加燃烧、冻结、减伤和其他状态。
6. 获得护盾、回复、金币、颜料与技能充能。
7. 执行净化、改色、抽牌和额外步数。
8. 写入统计、日志和碎片触发。

## 6. 伤害与资源公式

### 6.1 伤害

```text
raw = card_damage + character_bonus + resonance_bonus + relic_bonus + memory_bonus
amped = floor(raw * clamp(amplify_ratio, 0.50, 1.35))
after_resistance = floor(amped * clamp(color_resistance, 0.50, 1.00))
final_damage = max(after_resistance - effective_armor, 0)
```

- 单张普通色谱基础伤害建议 8-18。
- 稀有色谱基础伤害建议 16-32。
- 史诗色谱基础伤害建议 30-65。
- 明确支付 HP、诅咒或三步条件的终幕色谱可以达到 90，但单次最终伤害硬上限为 180。
- `amplify_ratio` 所有来源相加后限制在 0.50-1.35。
- 无视护甲只影响当前色谱，不清除敌人护甲状态。

### 6.2 效果重复

- 重复次数范围 1-4。
- 第 2 次起只重复数值型效果，不重复代价、抽牌、额外步数和碎片奖励。
- 默认重复倍率为 35%，角色或史诗效果可以提高到 60%。
- 所有重复伤害合并为同一张色谱的伤害来源。

### 6.3 单回合资源上限

| 资源 | 软上限 | 硬上限 |
|---|---:|---:|
| 护盾 | 30 | 60 |
| 回复 | 12 | 24 |
| 战斗金币 | 12 | 24 |
| 颜料 | 1 | 2 |
| 净化格 | 4 | 8 |
| 额外步数 | 1 | 2 |
| 抽牌 | 2 | 3 |

## 7. 色谱学派

| 学派 | 色相签名 | 主要身份 | 主要风险 |
|---|---|---|---|
| 红焰 | R | 伤害、燃烧、自伤爆发 | 生存压力 |
| 蓝霜 | B | 护盾、冻结、意图反制 | 输出偏慢 |
| 金辉 | G | 金币、颜料、资源转换 | 战斗即时收益偏低 |
| 灰蚀 | X | 净化、破甲、压力转换 | 条件依赖灰色 |
| 紫弦 | R+B | 先后顺序、重复、抽牌 | 操作次序要求高 |
| 翠生 | B+G | 回复、护盾、染色 | 爆发偏低 |
| 白昼 | R+B+G | 多色、净化、均衡收益 | 条件较难 |
| 黑曜 | X | 自伤、诅咒、高额结算 | 失败风险高 |
| 混色 | R+B+G | 跨色条件、复合效果 | 单项效率较低 |

中立色谱不参与谱序，但可以提供基础资源、删改牌组或处理异常状态。

## 8. 跨回合谱序共鸣

### 8.1 生命周期

- 上一玩家回合最后达成的有效色谱是本回合引音。
- 本回合第一张达成的有效色谱是应音。
- 引音与应音计算一次共鸣，并写入应音色谱的结算快照。
- 每回合最多触发一次；后续达成只更新尾音。
- 第 1 回合没有引音，因此不触发。
- 中立和诅咒不读取、不消费、也不更新谱序。

### 8.2 六类共鸣

| ID | 名称 | 配色条件 | 当前色谱修正 | 价值上限 |
|---|---|---|---|---:|
| `unison` | 同频和声 | 两签名有交集 | 最大数值效果 +20% | 8 BP |
| `violet` | 紫弦折射 | R 与 B 无交集组合 | 首个数值效果以 30% 重复一次 | 8 BP |
| `verdant` | 翠生回路 | B 与 G 无交集组合 | 获得 4 护盾；灰蚀≥4 时再净化 1 格 | 7 BP |
| `amber` | 熔金脉冲 | R 与 G 无交集组合 | 当前色谱 +4 伤害并获得 1 金币 | 7 BP |
| `daylight` | 白昼三和 | 联合集齐 R、B、G | 最大数值效果 +10%，净化 1 格 | 8 BP |
| `decolor` | 消色回声 | 任一签名含 X | 当前色谱忽略颜色抗性，灰蚀压力 -1 | 8 BP |

若某项收益无法生效，不自动转化成另一种收益。共鸣平均价值目标为单张已达成色谱总价值的 8%-15%。

### 8.3 可读性

- HUD 始终显示引音、本回合尾音与共鸣是否已消费。
- 卡面在可形成共鸣时显示名称和预计修正。
- 达成反馈先显示卡名，再显示共鸣，再显示最终数值。
- 快速结算可以缩短动画，但不能合并或跳过规则日志。

## 9. 敌人意图

### 9.1 正式类型

| 类型 | 公开信息 | 规则 |
|---|---|---|
| 攻击 | 预计伤害 | 扣除护盾后伤害 HP |
| 重击 | 预计伤害 | 必须提前一回合蓄力 |
| 防御 | 护甲值 | 本回合后获得护甲 |
| 污染 | 灰化格数 | 将非灰棋子转为灰色 |
| 锁格 | 位置与持续 | 指定棋子暂时不可交换 |
| 改色 | 颜色与格数 | 将指定棋子转换为目标色 |
| 封谱 | 手牌槽与持续 | 提高指定槽条件或禁止保留 |
| 抗性 | 学派与比例 | 降低对应色谱伤害 |
| 偷取 | 金币或颜料 | 资源不足时取现有值 |
| 回复 | 回复量 | 不超过最大 HP |

### 9.2 Boss 阶段

- 三名 Boss 均以 HP 65% 和 30% 为意图阶段阈值。
- 单次伤害跨越多个阈值时，阶段按顺序推进但只弹出一条合并提示。
- 阶段变化可以替换意图池、污染策略、抗性或色谱限制。
- 阶段变化不得插入额外玩家操作模式。

## 10. 五名角色

| 角色 | 身份 | 主动技方向 | 结算特性 |
|---|---|---|---|
| 烬歌 | 红焰爆发 | 强化下一张伤害色谱并施加燃烧 | 首次主动红色 4 连追加燃烧 |
| 凛镜 | 防御反制 | 下一张色谱追加护盾和冻结 | 打断蓄力获得护盾 |
| 洛恩 | 资源经营 | 下一张色谱追加金币 | 商店折扣与金色转换 |
| 弥砂 | 灰蚀净化 | 下一张色谱破甲并净化 | 首次污染获得护盾 |
| 伊澜 | 多色谱序 | 下一张色谱重复结算 | 三色完成与谱序容错 |

角色差异必须同时体现在起始牌组、被动、主动技和结算配置，禁止只调整 HP。

## 11. 誓约与四地图池

每章具有四张可复现地图模板：

| ID | 玩家名 | 内容倾向 | 进入方式 |
|---|---|---|---|
| `standard` | 均衡池 | 战斗、事件、整备均衡 | 守序之誓固定 |
| `risk` | 高风险池 | 精英、挑战和高收益偏多 | 破谱之誓固定 |
| `economy` | 事件经营池 | 事件、商店和宝箱偏多 | 见证之誓固定 |
| `archive` | 档案池 | 双事件、档案精英和记忆线索 | 完成任一记忆组后可在章节入口选择 |

- 单局 Seed 决定未被誓约固定的候选顺序。
- 档案池每章只可选择一次，必须保持起点到 Boss 可达。
- 模板 ID 写入 Run Save v4；读档恢复同一节点和边。
- 地图支持滚轮缩放、鼠标拖拽、按钮缩放和复位。

## 12. 记忆与战斗接入

- 正式档案为 30 枚碎片、10 组记忆，每组固定 3 枚。
- 默认发现 M01-M03；每局最多装备 3 枚回想。
- 回想效果只能修正开局资源、色谱数值、谱序、灰蚀、奖励或战后恢复。
- 重复碎片转化为记忆墨，不重复触发首次发现奖励。
- Profile v1 保存永久发现；Run Save v4 保存本局装备、誓约、节点领取状态和地图模板。

## 13. 统计

2.0 当前统计字段：

- 回合数、有效交换、无效交换、消除事件、消除格数、最大连线、最高级联。
- 色谱达成数、每回合平均达成数、各学派达成数、保留次数。
- 色谱伤害、燃烧伤害、角色被动伤害、最高单卡伤害与来源。
- 谱序推进、共鸣触发、共鸣率和六类共鸣次数。
- 护盾获得/吸收、回复、金币净值、颜料、净化格数与额外步数。
- 战斗胜负、普通/精英/Boss 战时长和四地图池使用情况。

退役统计不得出现在 2.0 结算页，但旧存档中的未知字段应被安全忽略。

## 14. 边界条件

| 场景 | 预期 |
|---|---|
| 第 1 回合达成色谱 | 正常结算，无共鸣 |
| 同事件达成三张 | 按槽位顺序逐张结算 |
| 当前卡击杀敌人 | 完成当前卡资源收益后胜利 |
| 达成后抽到新卡 | 新卡不读取过去事件 |
| 额外步数超过上限 | 限制到 2 |
| 重复次数超过上限 | 限制到 4 |
| 灰格超过 72% | 自动净化 2 格，一链一次 |
| 无合法交换 | 重排，不扣步数，不推进色谱 |
| 敌人跨越两个阶段 | 顺序推进，合并提示 |
| 未知条件或效果 | 数据校验失败，运行时安全跳过 |
| 损坏 Run Save | 拒绝加载或使用安全默认，不破坏 Profile |
| 旧存档未知字段 | 忽略并记录迁移日志 |

## 15. 测试矩阵

### 15.1 纯逻辑

- 6×6 生成、合法交换、重排、污染和 72% 自动净化。
- 3/4/5/6+ 色素、级联加成和交叉去重。
- 同名实例独立进度、精研实例隔离、保留守恒。
- 全部条件白名单和效果白名单。
- 色谱结算顺序、重复上限、伤害与资源硬上限。
- 六类共鸣、每回合一次、中立忽略和跨回合生命周期。

### 15.2 战斗集成

- 普通消除不会直接改变敌人 HP。
- 色谱达成在当前消除事件内完成伤害与资源结算。
- 同事件多卡、击杀卡、抽牌卡和额外步数卡顺序稳定。
- 五角色主动技和被动拥有不同结果。
- 十类敌人意图均公开、可结算、可清除。
- Boss 双阈值、快速结算和失败流程不重复回调。

### 15.3 内容与存档

- 114 张可收集色谱与 3 张事件诅咒通过数据校验。
