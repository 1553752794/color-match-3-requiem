# 《色彩勇者：三消镇魂曲》2.0 美术与 UI 规格

> 规格版本：2.0-pure-match-1  
> 当前架构：纯三消 + 色谱卡牌  
> 基准分辨率：1280×720  
> Figma 交付页：`2.0 Pure Match-3`

## 1. 体验目标

2.0 的战斗界面只有一个操作焦点：三消棋盘。色谱卡牌、谱序共鸣、敌人意图和日志围绕棋盘提供计划与反馈，不切换为第二套操作模式。

玩家在 3 秒内应能回答：

1. 本回合还剩几步。
2. 三张色谱各差什么条件。
3. 敌人下一步会做什么。
4. 当前交换会推进哪些色谱。
5. 最近一次伤害、护盾或资源来自哪张色谱。

冻结交互：

- 普通消除只显示色素、颜色基础效果和色谱进度，不显示敌人伤害数字。
- 色谱达成后，卡牌立即进入结算反馈，完成后回到空槽或补牌状态。
- 谱序共鸣作为应音色谱的附加层显示，不占据独立界面。
- 快速结算可以缩短动效，但不能省略卡名、来源和最终数值。

## 2. 视觉支柱

### 2.1 断色档案

世界像一份被反复删改的彩色档案：纸张纤维、玻璃压痕、墨迹遮盖、边角编号和局部彩色批注共同构成叙事层。UI 不能做成单色古卷，也不能用大面积装饰纹理牺牲可读性。

### 2.2 谱律舞台

棋盘是清晰、稳定、可长时间阅读的工作区；角色与敌人通过半身像、意图姿态、短促特效和状态图标存在于周边。战斗信息优先于场景装饰。

### 2.3 色形双编码

红、蓝、金、灰四类棋子同时使用颜色、轮廓和中心符号区分。九学派色谱使用边框纹样和角标组合，不能只靠底色。

## 3. 视觉令牌

### 3.1 颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| 背景墨黑 | `#17191D` | 最外层背景 |
| 面板炭灰 | `#24282E` | HUD 面板 |
| 纸白 | `#F1EEE6` | 主文字、档案纸面 |
| 次级灰 | `#AEB4BC` | 次级说明 |
| 红焰 | `#D94A45` | 红棋子、伤害、燃烧 |
| 蓝霜 | `#4C86C6` | 蓝棋子、护盾、冻结 |
| 金辉 | `#D5A638` | 金棋子、金币、价值 |
| 灰蚀 | `#777C83` | 灰棋子、污染、未知 |
| 翠生 | `#4D9B6A` | 回复、净化、翠生学派 |
| 紫弦 | `#8A61A8` | 顺序、返奏、紫弦学派 |
| 警告 | `#E56B3F` | 高风险意图、资源不足 |
| 成功 | `#65B879` | 达成、可选、已完成 |

- 正文与背景对比不低于 4.5:1；大号文字不低于 3:1。
- 禁用态降低饱和度并保留 60% 以上文字明度，不只降低透明度。
- 状态颜色不得覆盖学派颜色；状态使用角标、线型和图标补充。

### 3.2 棋子符号

| 颜色 | 轮廓 | 中心符号 |
|---|---|---|
| 红 | 上尖六边形 | 火痕 |
| 蓝 | 圆角菱形 | 雪纹 |
| 金 | 截角方形 | 刻度环 |
| 灰 | 圆形缺口 | 断线 |

棋子标准尺寸 48×48，视觉主体不小于 40×40，状态角标占 12×12。锁定、污染预告和可交换提示不能改变棋子布局尺寸。

### 3.3 字体

- 中文正文：Noto Sans CJK SC 或项目内等宽度授权字体。
- 数字：同字族 Tabular Numbers，HP、步数和条件计数不跳动。
- 页面标题 28px；面板标题 18px；卡名 16px；正文 15px；辅助信息 13px；最小 12px。
- 字号不随视口宽度缩放；紧凑布局通过换行、收栏和抽屉解决。
- 字距固定为 0。

### 3.4 几何与层级

- 页面边距 16px；面板间距 12px；控件内边距 8px；最小触控目标 48×48。
- 卡牌圆角 6px，常规面板圆角 4px，模态窗口圆角 8px。
- 不使用卡片嵌套卡片；色谱卡牌是战斗中的唯一高频卡片单元。
- 阴影仅用于模态、拖拽中对象和当前达成卡牌；普通面板用边线分层。
- Z 层：背景 0，场景 10，HUD 20，反馈 30，Tooltip 40，模态 50，系统提示 60。

│                          │ 色谱卡 3        │              │
│ 棋盘状态 / 交换预览      │ 主动技/保留     │ 结算日志    │
├──────────────────────────┴──────────────────┴──────────────┤
│ 底栏 80：资源、遗物摘要、结束回合、临时提示               │

精确约束：

- 顶栏高 56，底栏高 80，主内容高 560；左右安全边距各 16。
- 左栏 472：棋盘视觉区 420×420 居中，6×6 逻辑格不因提示变化而位移。
- 中栏 344：谱序轨高 72，三张紧凑色谱各高 124，主动技与保留区高 88。
- 右栏 400：敌人意图高 96，状态高 72，舞台高 216，日志高 152。
- 三列间距 12；任何 Tooltip 必须翻转方向以留在可视区。
- 角色或敌人名称过长时单行省略，悬停或聚焦显示全称。

## 5. 战斗组件

### 5.1 棋盘

- 默认显示全部合法棋子，不常驻显示可交换提示。
- 选中棋子用 2px 纸白外框和轻微抬升；相邻合法目标显示细线框。
- 无效交换在 160ms 内回位并说明原因，不扣步数。
- 级联按层显示 `级联 2`、`级联 3`，不遮挡下一层棋子落位。
- 锁格用闭合框与小锁图标；污染预告用虚线遮罩；色盲模式保留形状变化。
- 死局重排先显示“棋盘重排”，重排不触发色谱进度动画。

### 5.2 色谱卡牌

紧凑卡尺寸 312×124，固定包含：

1. 学派角标、稀有度和卡名。
2. 条件摘要及当前/目标计数。
3. 预期效果与关键数值。
4. 保留、封谱、精研和可共鸣状态。

- 条件进度采用分段条和数字，不用环形小字。
- 能在本次交换达成的卡牌显示白色轮廓和“将达成”图标。
- 无法达成时显示具体原因，例如“本回合缺少蓝色事件”，而不是只变灰。
- 达成后卡牌向前抬升 8px，显示卡名，立即执行结算反馈；整个过程不改变棋盘尺寸。
- 同事件多卡按槽位从上到下排队，当前卡高亮，其余保持可见。

### 5.3 谱序轨

- 显示上一回合引音、本回合预计应音、共鸣名称和本回合是否已消费。
- 第一回合显示“引音为空”，不使用错误或警告样式。
- 可形成共鸣时只高亮对应应音卡的边框，不在三张卡上重复大段说明。
- 共鸣结算顺序为：卡名 -> 共鸣名 -> 修正值 -> 最终结果。

### 5.4 敌人意图

| 意图 | 图标形状 | 必显信息 |
|---|---|---|
| 攻击/重击 | 刃形 | 预计伤害、蓄力状态 |
| 防御/回复 | 盾形/十字 | 数值 |
| 污染/改色 | 棋格形 | 格数、目标颜色 |
| 锁格 | 方锁 | 位置、持续回合 |
| 封谱 | 封条 | 目标槽、条件增量或持续 |
| 抗性 | 断环 | 学派、减伤比例 |
| 偷取 | 缺口币 | 资源类型和数值 |

- 当前意图始终展开，后续意图预览使用小图标和短句。
- Boss 阶段变化用一次合并横幅，不遮挡棋盘超过 700ms。
- 意图若因角色、遗物或记忆被修正，原值划线并显示最终值。

### 5.5 结算反馈与日志

- 伤害数字从敌人位置出现，颜色跟随来源学派并带卡名缩写。
- 护盾、回复、金币、颜料和净化使用各自图标与数值，不复用伤害样式。
- 日志默认显示最近 4 条；相同来源可折叠，但必须保留展开能力。
- 每条日志格式：`[来源] 条件/修正 -> 最终结果`。
- 普通消除日志格式：`[消除] 红×4，色素 +5，推进 2 张色谱`，不显示敌人伤害字段。

## 6. 页面规格

### 6.1 主菜单

- 第一视口直接展示产品名“色彩勇者：三消镇魂曲”和“继续远征 / 新的远征 / 档案 / 设置 / 退出”。
- 背景使用三章地点的实景式绘制，主体清晰，不使用纯装饰抽象背景。
- 有有效 Run Save v4 时“继续远征”为主操作；无存档时置灰并说明。
- 版本号 `2.0.0` 放在右下安全区。

### 6.2 角色与誓约选择

- 左侧五名角色纵列，中部显示当前角色全身或半身立绘，右侧显示起始牌组、被动、主动技和专属池摘要。
- 角色卡同时显示 HP 与构筑身份，不能只用颜色区别。
- 誓约使用三项互斥选项：守序、破谱、见证；选中后直接显示收益、代价和对应地图池。
- A0-A10 使用步进器与规则摘要，确认按钮固定在右下。

### 6.3 地图

- 节点采用战斗、精英、事件、商店、营火、宝箱、挑战、Boss 八类图标。
- `standard`、`risk`、`economy`、`archive` 四类模板在章节入口显示名称、节点分布摘要和来源条件。
- 鼠标滚轮以指针位置缩放，范围 0.75-1.65；左键空白区或中键拖拽；提供放大、缩小、复位图标按钮。
- 拖拽离窗立即结束；缩放和拖拽不能让全部可达节点移出可视区。
- 未确认节点只显示类型和已解锁情报，不提前泄露随机奖励。

### 6.4 记忆档案

- 顶栏固定显示 `记忆 00/30`、`记忆组 00/10`、记忆墨和 3 个回想槽。
- 主区按 10 组排列，每组固定 3 个槽位；未知项显示来源类型和章节轮廓。
- 详情展示事实摘要、五角色视角、局内效果、关联事件和结局证据。
- 装备与卸下使用明确按钮；拖放只作为快捷方式。

### 6.5 事件与奖励

- 事件页面为全宽场景带，不把正文和插画各放进独立卡片。
- 标题、场景图、正文和 2-4 个选择按阅读顺序排列；每个选择明确显示代价、收益和条件。
- 记忆首次发现使用物证近景，右侧显示标题与短文案；重复项显示转化为记忆墨。
- 战后奖励一次最多展示 3 张色谱；详情比较当前实例与精研结果。

### 6.6 结算页

- 结局标题、角色、誓约与三章路线是第一屏信号。
- 主要统计固定为：有效交换率、平均每回合达成、最高级联、共鸣率、最高单卡伤害。
- 次级统计包括学派分布、承伤、护盾、经济、记忆发现和 Boss 干预。
- 结局证据逐条列出已满足条件；未知隐藏结局只显示轮廓。

### 6.7 设置与无障碍

- 音频：总音量、音乐、音效。
- 显示：全屏、窗口尺寸、UI 缩放、屏幕震动、闪光强度。
- 战斗：快速结算、交换提示、结算日志展开、战斗速度 0.5x-2.0x。
- 无障碍：高对比棋子、色形双编码、减少动态、字幕、焦点强化。
- 所有滑杆显示数值，二元设置使用开关，模式选项使用分段控件。

## 7. 动效与音频

### 7.1 时长

| 动作 | 标准时长 | 快速结算 |
|---|---:|---:|
| 交换 | 140ms | 90ms |
| 消除 | 180ms | 100ms |
| 下落 | 180-260ms | 110-160ms |
| 色谱达成抬升 | 220ms | 120ms |
| 单张色谱结算 | 320-650ms | 160-260ms |
| Boss 阶段提示 | 700ms | 400ms |
| 记忆首次发现 | 900-1400ms | 600-800ms |

- 动效只使用透明度、位置和缩放，避免改变布局测量值。
- 减少动态开启后取消大幅位移、视差和震动，保留必要的状态切换。
- 同事件多卡使用节奏递进，不并发覆盖卡名和最终数值。

### 7.2 声音层级

- 四色消除各有短促音色，级联只提高层级，不无限提高音量。
- 色谱达成使用学派主题短句，共鸣增加第二声部。
- 敌人意图、受击、护盾、净化、记忆发现和 UI 操作使用独立声类。
- 音频不能替代视觉信息；关闭音效后所有规则仍可读。

## 9. Figma 2.0 文件规格

现有 `1.5 Release UI` 仅作为历史参考。2.0 必须建立独立页面 `2.0 Pure Match-3`，避免旧组件与当前语义混用。

| Frame | 内容 | 必含状态 |
|---|---|---|
| `00_foundations` | 颜色、字体、间距、图标、棋子、学派 | 默认/高对比/禁用 |
| `01_expedition_setup` | 五角色、三誓约、A0-A10 | 首次/已解锁/条件不足 |
| `02_map_four_pools` | 四类地图池与缩放控件 | 默认/缩放/拖拽/档案锁定 |
| `03_combat_resonance` | 单一三消战斗焦点 | 常态/将达成/多卡结算/共鸣/Boss 阶段 |
| `04_memory_archive` | 30 枚记忆、10 组、3 槽 | 未知/发现/完成/装备 |
| `05_ending_evidence` | 结局与统计 | 胜利/失败/复调终局/未知证据 |
| `06_events_rewards` | 事件、记忆拾取、战后奖励 | 条件满足/不足/重复记忆 |
| `07_settings_accessibility` | 设置与无障碍 | 默认/高对比/减少动态 |

`03_combat_resonance` 只呈现棋盘、三张色谱、谱序、意图和日志。`05_ending_evidence` 的五项首要指标固定为有效交换率、平均每回合达成、最高级联、共鸣率、最高单卡伤害。

组件使用 Auto Layout、变量和语义化 Variant；棋盘、卡牌、意图、按钮和数字计数器必须有稳定尺寸。所有最长中文、四位 HP、五位金币与 A10 状态均需在组件内测试。

## 10. 响应式规则

| 视口 | 布局 |
|---|---|
| 1920×1080 及以上 | HUD 最大宽 1600 居中，扩大舞台与留白，不放大字号 |
| 1280×720 | 三列标准布局 |
| 1024×576 至 1279×719 | 右栏收为 72px 意图轨，点击展开抽屉；中栏卡牌压为 276×112 |
| 960×540 | 顶栏 44、底栏 64；日志默认关闭；保持棋盘完整 |
| 超宽屏 | 背景延展，操作区最大宽固定，不拉伸棋盘 |

- UI 缩放 125% 时启用紧凑布局，不对整棵界面直接缩放。
- 动态文字不得改变棋盘、卡牌、图标按钮、计数器和意图格的几何。
- 安全区上下左右至少 16px；移动横屏额外读取系统安全区。

## 11. 验收清单

### 11.1 布局

- [ ] 1280×720 下棋盘、三张色谱、谱序、敌人意图和步数同时可见。
- [ ] 1024×576、960×540、1600×900、1920×1080、2560×1080、1920×1200 无裁切和重叠。
- [ ] 125% UI 缩放与最长文本不改变固定格式组件尺寸。
- [ ] Tooltip、Toast、菜单和模态窗口始终位于安全区内。
- [ ] 地图滚轮缩放、拖拽、按钮缩放与复位行为一致。

### 11.2 可读性

- [ ] 四色棋子在灰度截图中仍可由轮廓和符号区分。
- [ ] 普通消除反馈不会被误认成敌人伤害。
- [ ] 色谱达成、共鸣修正与最终结果顺序清晰。
- [ ] 玩家能从日志追溯每次伤害、护盾、控制和资源来源。
