# 《色彩勇者》2.2 Remaster 规格

> 目标版本：2.2.0  
> 文档性质：已批准更新的设计侧车文档  
> 基线：2.0 纯三消 + 2.1 断点续行与地图记忆  
> 状态说明：本文件区分已存在、2.2 本轮实施中和未来规划；未将未来规划写成已交付功能。

## 1. 版本定位

2.2.0 是可靠性、反馈可读性和界面承载能力更新，不是完整的局外成长、经济或战斗平衡重做。

本版本继续遵守 2.0 核心闭环：

`有效交换 -> 消除与级联产色素 -> 推进色谱 -> 色谱即时结算 -> 敌人行动`

普通消除仍不直接扣除敌人 HP；色谱、角色、遗物、谱序和公开敌人意图仍是战斗规则来源。

## 2. 当前已存在的基线

- Godot 4.6，主场景为 `res://scenes/Main.tscn`。
- 6×6、红/蓝/金/灰四色棋盘；无合法交换时重排，灰蚀死局有净化保护。
- Run Save v4 与 Profile v1。
- 2.1 已加入稳定检查点、战斗中断恢复、原子存档替换、备份回退、地图视图持久化和扩展色谱计数恢复。
- 当前实际色谱目录为 119 项：116 张可收集色谱与 3 张事件诅咒。117 是旧 2.0 文档基线，不再作为当前实际目录数量。
- 现有内容仍包括 72 件遗物、54 个事件、30 枚记忆、10 组记忆和三章四类地图池。

## 3. 2.2 本轮更新范围

### 3.1 棋盘快照原子性与权重安全

- `Board.create_snapshot()` 输出棋盘、权重和事件序号的深拷贝。
- `Board.restore_snapshot()` 先完整校验，再一次性提交；拒绝时保留当前棋盘、选中状态、忙状态、锁定状态和可视节点。
- 校验 6×6 形状、支持颜色、有限正数事件序号、无预成消除和至少一个合法交换。
- 权重过滤未知颜色、非数值、非有限值和非正值；使用最大值缩放后归一化，避免大浮点数求和溢出。
- 确定性或极端权重造成固定点补充时，不继续制造虚假级联事件，恢复为可玩的棋盘。
- 2.1 的战斗中断恢复继续有效；2.2 只强化棋盘快照边界，不改变 Run Save v4/Profile v1 合同。

### 3.2 棋子可读性、真实 Tooltip 与动效生命周期

- 继续复用现有宝石 PNG：`assets/ui_2_2/gems/ruby_smoothed.png` 与 `sapphire_smoothed.png`，不宣称已有新的 AI 位图。
- 棋子同时使用颜色、宝石轮廓和中文标识，保持 48×48 固定承载。
- Tooltip 描述实际规则：色素、技能充能、红焰燃烧、蓝霜 30% 冻结概率、金辉金币及战斗上限、灰蚀净化/转化。
- Tooltip 不得把普通消除写成“直接伤害”或“基础伤害”。
- 减少动态或快速结算开启时，清除和生成反馈直接进入最终状态。
- 棋子复用前先取消旧 Tween；补充、重建、离树时不得让旧动画回写到新棋子状态。

### 3.3 有类型的战斗反馈与非阻塞反馈条

`BattleManager.combat_feedback_emitted` 使用 `kind / title / detail / color / duration` 合同。

反馈类型包括消除、色谱结算、谱序共鸣、敌人行动、胜利和失败。反馈顺序保持：

`消除 -> 色谱 -> 共鸣/最终结果 -> 敌人行动或终局`

普通消除只说明色素、技能充能、颜色基础效果和级联，不显示敌人伤害数字。色谱反馈包含卡名和完整结算伤害；终局反馈先于切换场景的回调。

Main 使用单个不阻塞输入的反馈条，按优先级压低过期低优先级消息；不使用模态教程或遮挡棋盘的强制弹窗。

### 3.4 Main 双栏与更宽舞台

- 提高棋盘和色谱区的可用宽度，保留单一三消操作焦点。
- 三张色谱使用更宽的横向承载和水平滚动保护，固定卡牌最小尺寸，反馈条不改变棋盘几何。
- HUD 更新同步替换旧卡节点，避免重复刷新留下排队删除的旧卡。
- 清屏时立即隐藏并禁用旧页面，再释放节点；屏幕代际检查阻止旧战斗回调继续绘制到新页面。
- 反馈、Tooltip 和日志不得阻塞交换、技能、保留或结束回合。

### 3.5 重复卡刷新与旧场景生命周期

同名色谱仍以独立 `instance_id` 识别。2.2 只修复显示刷新和生命周期，不改变同名卡独立进度、保留和结算规则。

- 刷新卡牌时按当前实例状态重建可见卡面。
- 重复刷新不得重复连接保留回调或保留幽灵节点。
- 旧战斗页面隐藏、禁用并进入释放流程后，不再处理延迟事件。

### 3.6 设置中的首次事件持久白名单

首次事件提示使用白名单：

`character_choice / vow_choice / first_battle / first_swap / first_spectrum / first_resonance / first_enemy_intent`

- 只记录白名单 ID，未知 ID 忽略。
- 提示写入已有日志或非阻塞反馈，不新增阻塞式教程流程。
- 设置保存失败不得破坏当前运行状态。
- 本项不新增金币、掉落、价格、经验或其他经济规则。

## 4. 明确不属于 2.2 交付

- 没有完整局外 Meta Progression、天赋树、商店重做或遗物系统重做。
- 没有全量战斗数值重做、A0-A10 重做或经济平衡重做。
- 没有新增基础棋子颜色。
- 没有新的中途存档协议；2.1 的稳定检查点恢复继续沿用。
- 没有新的 AI 生成位图：Infinite Canvas 已重新连接本地 agent，但 3 次图像请求均因 `No available compatible accounts` 失败。
- 没有把 Figma、导出包或新图像产物写成 2.2 已交付结果。

## 5. 验证边界

本轮审计必须分别验证棋盘快照安全、Tooltip 与动效、战斗反馈顺序、1280×720 双栏舞台、卡牌刷新、旧场景停用和首次事件白名单。验证结果由审计报告补录；在补录前不得把测试或导出写成通过。
