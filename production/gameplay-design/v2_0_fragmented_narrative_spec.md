# 《色彩勇者》2.0 碎片化叙事与世界观规格

> 规格版本：2.0-pure-match-1  
> 当前架构：纯三消 + 色谱卡牌  
> 内容规模：30 枚记忆 / 10 组记忆 / 54 个事件 / 每章 4 类地图池  
> 存档：Run Save v4 / Profile v1

## 1. 叙事目标

“断色回廊”不是独立图鉴，而是贯穿多局的证据构筑。玩家在地图、事件、战斗和结局中发现记忆，通过不同角色的证词拼出同一段历史；记忆既改变可见信息，也提供受控的局内构筑选择。

叙事循环：

`发现记忆 -> 写入档案 -> 装备回想 -> 解锁事件证词与档案路线 -> 干预棋盘或色谱规则 -> 形成结局证据`

设计底线：

1. 每条叙事奖励至少改变一个可观察状态：地图情报、事件选项、棋盘、色谱、敌人意图、资源或结局证据。
2. 跨局档案主要提供信息和构筑选择，不永久增加基础 HP、基础伤害或初始金币。
3. 当前正式规模固定为 30 枚记忆，组成 10 组完整记忆，每组 3 枚。
4. 每局最多装备 3 枚回想；重复发现转化为记忆墨，不重复发放首次奖励。
5. 普通消除不直接伤害敌人。所有叙事战斗效果只能修改色素、色谱结算、谱序、棋盘或公开意图。

## 2. 世界规则

世界中的颜色不是元素，而是现实被理解和执行的方式，统称为“谱律”。

- **红焰**：把意志写成不可撤回的行动，代价是伤痕与失控。
- **蓝霜**：保存顺序、延缓后果并校验因果，代价是僵化与迟滞。
- **金辉**：给价值、债务与交换定价，代价是把关系变成账目。
- **灰蚀**：删除冲突信息，让现实暂时恢复稳定；被过度调用后会吞掉差异。
- **扩展学派**：紫弦、翠生、白昼、黑曜与混色，是多种谱律组成的解释方式，不是额外棋子颜色。

战斗与世界观遵循同一条因果链：

`消除提取色素 -> 色谱把色素组成句法 -> 色谱达成立即改写现实`

普通消除只是取材和排列，不承担敌人 HP 输出。色谱卡牌承担伤害、护盾、控制、回复、资源与棋盘改造；谱序共鸣只修正应音色谱的当次结算。

## 3. 断色历史

综合色战时期，各城邦试图用单一谱律重写法律、记忆与价值。无色王原是协调各声部的首席调律师。他颁布“断色令”，把完整历史拆成彼此不相认的片段，再用灰蚀删除冲突处，以此终止战争。

断色令留下三个长期后果：

1. 被删除的矛盾沉入连接三章地域的断色回廊。
2. 保存、校准和执行断色令的机构，逐渐具象为灰蚀龙、镜湖乐监与无色王三名 Boss。
3. 每个人只能保留与自身谱律相容的证词，因此互相冲突的版本可能同时包含真相。

| 地点 | 对外叙事 | 被隐藏的事实 | 纯三消战斗表达 |
|---|---|---|---|
| 灰雾边境 | 灰雾来自失控巨龙 | 灰蚀龙曾是吞入矛盾档案的边境记录官 | 污染、灰色增权、锁格、红焰抗性 |
| 镜湖工坊 | 工坊维护唯一正确的谱律 | 乐监复制标准答案并删除无法复制的人 | 改色、冻结、封谱、顺序条件 |
| 无色王庭 | 无色王以绝对中立终止战争 | 王把自己的多份记忆拆给三名守门者与回廊 | 多色限制、抗性轮换、意图遮蔽、压力累积 |

## 4. 五名角色视角

| 角色 | 过去 | 证词关注点 | 会回避的事实 | 文案关键词 |
|---|---|---|---|---|
| 烬歌 | 曾奉命焚毁无法归档的谱页 | 命令、反抗、伤口 | 自己参与过清除 | 火痕、偿还、选择 |
| 凛镜 | 保存了一帧被判定为错误的倒影 | 顺序、矛盾、前兆 | 曾提交错误校验 | 次序、倒影、证据 |
| 洛恩 | 用账本协助王庭追踪颜料 | 获利者、成本、债务 | 曾把人名写成货号 | 价格、抵押、缺口 |
| 弥砂 | 从灰雾残留中拾得他人记忆 | 空位、残留、删改痕迹 | 自己可能是多份记忆的拼合 | 噪声、借名、余迹 |

角色差异必须同时出现在事件措辞、角色专属选项、Boss 证词和结局旁白中，不能只替换姓名。

## 5. 记忆系统

### 5.1 状态与边界

- `discovered`：永久发现，写入 Profile v1。
- `viewed_by`：已读角色视角，按角色独立保存。
- `completed_group`：同组三枚均发现后永久解码。
- `equipped_recollections`：本局装备的回想，最多 3 枚，写入 Run Save v4。
- `memory_ink`：重复发现获得 1 点，作为档案事件的选择成本。
- 默认发现 M01-M03，使新玩家能立即看到一个完整记忆组和档案池说明。
- 解码任意完整记忆组后，章节入口可选择 `archive` 档案池。

## 7. 事件内容

2.0 正式事件总量为 54 个：保留 36 个既有事件，并新增 18 个碎片叙事事件。新增事件组织为 6 条三段链：

| 链 ID | 三段主题 | 主要产出 |
|---|---|---|
| E-ARCHIVIST | 任命书 -> 雾根 -> 旧名 | M04-M06、灰雾证词 |
| E-COURT | 税册 -> 王锁 -> 空格 | M08、M11-M12、王庭路线 |
| E-MIRROR | 第零版 -> 停工 -> 掌声 | M13、M16、M18、镜湖证词 |
| E-CORRIDOR | 脚印 -> 门背 -> 见证席 | M20-M21、档案路线 |
| E-CALIBRATION | 误差 -> 延迟命令 -> 辞呈 | M25-M27、Boss 干预 |
| E-ENDINGS | 灰雾胜利书 -> 另一终章 -> 重叠署名 | M28-M30、复调终局 |

事件链规则：

1. 首段只进入允许章节和地图池；后续段读取 Run Save v4 的链状态。
2. 事件在节点首次打开时由 `run_seed + chapter + node_id` 确定并保存，重载不得重抽。
3. 条件不足的选项必须显示原因，不能扣除资源或推进链。
4. 已发现记忆再次出现时改发 1 记忆墨；记忆墨不足时不能进入付费档案选项。
5. 角色专属文本可以改变选项和代价，但不能绕过同一事件的收益上限。

## 8. 四类地图池

每章都提供四张可复现模板，而不是四条固定路线：

| ID | 名称 | 节点倾向 | 进入规则 |
|---|---|---|---|
| `standard` | 均衡池 | 战斗、事件与整备均衡 | 守序之誓固定 |
| `risk` | 高风险池 | 精英、挑战与高收益偏多 | 破谱之誓固定 |
| `economy` | 事件经营池 | 事件、商店和宝箱偏多 | 见证之誓固定 |
| `archive` | 档案池 | 双事件、档案精英和记忆线索 | 解码任意记忆组后可选 |

- 三项誓约分别固定前三类地图池；档案池是满足记忆条件后出现的第四类选择。
- 所有模板必须保证起点到 Boss 可达，并至少存在两次有效路线分岔。
- 隐藏边只能在当前节点相邻层之间连接，不能跳过 Boss 或连接已访问节点。
- 地图模板、已显形情报、事件分配和隐藏边写入 Run Save v4。

## 9. Boss 记忆干预

| Boss | 证据条件 | 战前二选一 | 边界 |
|---|---|---|---|
| 灰蚀龙 | 完成 G02 | 首次污染少 2 格；或首次红焰抗性失效 | 每战一次，最低污染 0 |
| 镜湖乐监 | 完成 G05 或 G06 | 首次封谱持续 -1；或首次改色少 2 格 | 不改变已建立的色谱快照 |
| 无色王 | 完成 G04 或 G10 | 首次锁格少 2 格；或第一次抗性轮换延后 1 回合 | 仍保留公开意图与阶段阈值 |

Boss 在 HP 65% 与 30% 进入新阶段。阶段变化只能替换污染、锁格、改色、封谱、抗性和意图节奏，不能插入第二套玩家输入。

## 10. 结局 2.0

### 10.1 判定输入

- 是否击败无色王。
- 红、蓝、金、灰四类消除事件比例。
- 九学派色谱达成比例与谱序共鸣率。
- 当前角色、誓约、三章地图池与角色挑战结果。
- 已发现记忆、完成记忆组、装备回想与关键事件链。
- A0-A10、Boss 干预选择和最终灰蚀压力。

### 10.2 优先级

1. 远征失败。
2. 复调终局：完成 G10、至少完成 6 组记忆、三种基础学派均达到最低使用线并击败无色王。
3. 灰蚀终局：最终灰蚀压力达到阈值，或灰蚀学派显著占优。
4. 红焰、蓝霜、金辉主色结局。
5. 平衡结局。

结算页必须列出触发结局的可核对证据，不能只显示一段无法追溯的旁白。未满足的隐藏条件只显示轮廓和来源提示。

## 11. UI 与文案

### 11.1 档案页

- 顶部显示 `已发现 / 30`、`已完成组 / 10` 和记忆墨。
- 中部按十组展示三个固定槽位；未知条目显示来源类别，不显示正文。
- 右侧展示事实摘要、五角色视角、规则效果和关联事件。
- 回想装备使用 3 个稳定槽位，拖放和按钮操作结果一致。

### 11.2 战斗与地图

- 发现记忆使用右侧短提示，不遮挡棋盘、色谱卡牌或敌人意图。
- Boss 干预在战前选择，战斗中只显示已选效果及剩余次数。
- 地图用独立图标区分四类模板；档案线索用书签形状，不只依赖颜色。
- 所有叙事效果日志必须说明它修改的是棋盘、色谱、谱序、意图或资源。

### 11.3 文案规范

- 每枚记忆：标题 4-10 字，正文 28-70 字，来源提示 12-28 字。
- 每个角色视角：18-45 字，只增加立场，不复述事实摘要。
- 选项先写行为，再写明确代价与收益。
- 不使用超出实际规则的战斗隐喻；所有当前 2.0 文案统一采用棋盘、消除、色素、色谱、谱序与结算语义。

## 12. 存档

### Run Save v4

保存角色、誓约、A0-A10、地图模板、节点与边、事件分配、事件链、牌组、遗物、回想槽、已领取节点、Boss 干预、结局证据和局内统计。战斗中途存档不在 2.0 范围；续局从节点外状态恢复。

### Profile v1

保存 M01-M30 的发现状态、五角色阅读状态、十组完成状态、记忆墨、默认与最近装备槽、Boss 遭遇记录及已见结局。新开远征不能清空 Profile。

迁移或读档时，未知记忆 ID、重复槽位、超过 3 个装备和负数记忆墨必须清洗；损坏的 Run Save 不得覆盖有效 Profile。

## 13. 测试与验收

- M01-M30 ID 唯一，十组各引用 3 枚且无遗漏、无重复。
- 默认发现恰为 M01-M03，装备槽始终为 0-3 枚。
- 54 个事件均可达；18 个新增叙事事件的链状态可存取且不能重复领奖。
- 每章 `standard`、`risk`、`economy`、`archive` 均可从起点到达 Boss。
- 发现、重复发现、记忆墨、组完成与角色阅读状态可在 Profile v1 往返。
- 普通消除不会因记忆效果直接改变敌人 HP。
- Boss 干预只修改公开的棋盘或色谱规则，并且每项每战最多触发一次。
- 同一 Seed、角色、誓约与记忆状态生成相同地图、事件和奖励。
- 结局证据能解释判定结果，复调终局缺任一必要条件时不可触发。
- 当前 2.0 文案通过禁用术语检查；旧架构措辞只允许存在于明确标注的版本历史章节。

## 14. 完成定义

1. 30 枚记忆、10 组记忆、3 个回想槽和 Profile v1 可完整追踪。
2. 18 个新增叙事事件与 36 个既有事件共同构成 54 个可达事件。
3. 三项誓约与第四类档案池能形成四种每章地图轮换。
4. 五名角色对关键证据给出可辨识的不同视角。
5. 叙事效果完全服从纯三消 + 色谱卡牌的战斗闭环。
6. 结局由可见证据驱动，并能在结算页解释。
