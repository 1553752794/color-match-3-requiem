# 色彩勇者：三消镇魂曲 2.0.1 正式测试计划

- 计划日期：2026-08-06
- 测试版本：2.0.1
- 引擎：Godot 4.6.3 stable Mono
- 主场景：`res://scenes/Main.tscn`
- 测试策略：协作者并行静态审查与用例设计，主任务单实例串行执行 Godot

## 一、测试目标

1. 验证三消、色谱、角色、敌人、遗物和事件构成的核心循环可以完整通关。
2. 验证任何合法操作、外部改色、读档恢复和章节切换都不会形成软锁或无解状态。
3. 验证竖向地图只显示当前模板的实际可达子图，缩放、拖拽和节点点击在目标分辨率可用。
4. 验证账号档与局内档在异常中断、旧版本数据和重复领奖时保持一致。
5. 验证正式包的内容规模、资源引用、版本元数据和 Windows 启动流程。

## 三、测试环境与执行纪律

- 使用 `Godot_v4.6.3-stable_mono_win64_console.exe`。
- 自动化使用隔离的 `APPDATA` 与 `LOCALAPPDATA`。
- 所有 Godot 测试串行执行，禁止并发引擎实例。
- 诊断命令使用 `--disable-crash-handler`，日志写入 `artifacts/qa/`。
- UI 截图使用 Windows 显示驱动和 GL Compatibility；纯逻辑测试使用 `--headless`。
- 1280×720 为最低验收分辨率，1600×900 为桌面扩展验收分辨率。
