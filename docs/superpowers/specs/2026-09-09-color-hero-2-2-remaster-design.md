# 色彩勇者 2.2 重制设计

**日期：** 2026-09-09

## 目标

在保持“纯三消 + 色谱即时结算”核心规则、Run Save v4/Profile v1 兼容和 Godot 4.6.3 运行边界不变的前提下，将当前 2.1.0 基线提升为更容易理解、更有反馈、更适合重复游玩的 2.2 版本。

## 当前审计结论

- Godot 4.6.3 编辑器冷解析通过。
- 全量 36 个测试脚本通过。
- 现有核心系统已经具备较强的数据校验、存档恢复和发布验收能力。
- 本轮重点不是推翻底层规则，而是补齐自动化尚未充分覆盖的玩家体验层：首局引导、战斗反馈、路线决策、视觉主题和真实启动烟测。

## 2.2 产品方向

### 1. 战斗可读性

- 棋盘、色谱手牌、敌人意图、回合剩余交换次数形成明确的扫描顺序。
- 色谱达成显示“颜色来源 → 达成条件 → 即时效果 → 共鸣修正 → 敌人变化”的短反馈链。
- 通过轻量动画、颜色高亮和状态标签区分普通消除、色谱完成、共鸣和敌人行动。
- 不新增第二操作层，不恢复 1.x 的瞄准/发射流程。

### 2. 首局体验

- 角色选择页直接说明角色玩法、主动技和推荐操作风格。
- 誓约选择页说明风险与收益，并让玩家知道其对应地图池。
- 第一场战斗提供一次性提示，不改变规则、不阻塞玩家。
- 首次完成色谱、首次触发共鸣、首次遭遇敌人意图时提供短提示。
- 引导状态写入本地设置或 Profile，不污染 Run Save 核心结构。

### 3. 路线与构筑节奏

- 地图页突出当前节点、可达节点和节点类型差异。
- 普通战斗奖励保持快速，精英/事件/商店提供更强决策。
- 2.2 只调整展示和少量奖励节奏，不重新平衡全部 117 张色谱与 72 件遗物。
- 所有奖励事务继续先落盘，再播放展示。

### 4. 视觉重制

- 统一“断色回廊”主题：深色背景、四色棋子、彩色谱线、金色关键行动。
- 使用 Infinite Canvas 产出视觉方向板、战斗 HUD 布局参考、角色/敌人反馈素材建议。
- 优先替换可安全引用的背景、棋子、按钮状态和反馈特效素材。
- 生成素材必须保留原始比例，并经过 Godot 实际运行截图验证。
- 不编辑 `.godot/imported` 生成文件。

## 技术边界

- 保持 `Main.tscn` 为主场景。
- 保持 `GameManager`、`SaveManager`、`SettingsManager` 自动加载名称和存档版本。
- 新增体验状态优先放入 `SettingsManager` 或已有 Profile 扩展字段，禁止把场景节点引用放入自动加载。
- GDScript 使用静态类型、信号通信和 Godot 4.6 API。
- 不引入第三方插件或新运行时依赖。

## 验收标准

1. 原有 36 个测试继续全部通过。
2. 新增测试覆盖首局引导状态、战斗反馈事件、HUD 文案契约和素材路径。
3. 主场景可通过安全脚本启动，能够进入主菜单、角色选择、地图和战斗。
4. 1280x720 和 1600x900 下无关键 UI 重叠、文本溢出或棋盘裁切。
5. 重新导出的 Windows 包通过发布包完整性检查。
6. 版本号更新为 `2.2.0`，并补充版本记录与启动说明。

## 分阶段交付

- Phase A：审计、烟测、体验状态与测试基线。
- Phase B：战斗 HUD/反馈重制和首局引导。
- Phase C：地图/奖励节奏和视觉资产接入。
- Phase D：回归、截图 QA、导出 2.2.0。
