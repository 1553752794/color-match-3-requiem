# 色彩勇者 2.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有纯三消战斗规则和 Save v4 的前提下，加入色谱构筑标签、目标色谱、只读交换预览、奖励协同信息和流派统计。

**Architecture:** 沿用当前 `GameData` 静态数据、`BattleManager` 战斗状态、`Board` 棋盘解析、`Main` UI 组合和独立 GDScript 测试。预览只读取棋盘和战斗状态，不修改任何 live state；目标色谱作为 BattleManager 快照字段恢复。标签是数据层元信息，不直接参与伤害计算。

**Tech Stack:** Godot 4.6.x, GDScript, headless script tests, existing Save v4 / Profile v1.

**Spec:** `docs/superpowers/specs/2026-09-23-color-hero-2-4-design.md`

## Global Constraints

- 保留 6×6 四色棋盘、三步回合、三张色谱、即时结算和谱序共鸣。
- 不增加基础颜色，不改 Save v4/Profile v1 版本号。
- 不编辑生成的 Godot 导入元数据。
- 预览不得改变棋盘、色谱进度、统计、随机状态或存档。
- 所有新增行为必须在 `1280×720` 和 `1600×900` 下保持可读。
- 项目目录没有可用 Git 仓库；每项任务以专项测试、冷解析和工作区变更记录作为验证边界，不执行提交。
